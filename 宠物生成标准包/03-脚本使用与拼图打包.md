# 03 · 脚本使用与拼图打包

> 想**不写 prompt、直接传参考图一键生成**？见 `05-参考图一键生成.md`（`generate.py` 会自动跑完本页的 fit → assemble → validate → make_pet）。本页是给「自己出图后手动拼装」用的。
>
> 生成好 73 张透明底 PNG 后，用这里的脚本把它们拼成标准精灵图、校验、打包。
> 脚本只做确定性机械活（拼格、数 73/15、填映射、打 ZIP），**不生成图片、不抠图**。

---

## 一、完整流程

```
生成图(02文档)
   │  松散 PNG（任意尺寸、透明底）
   ▼
fit.py        缩放定位成 192×208 标准帧
   │
   ▼
assemble.py   标准帧 → 1536×2288 精灵图（+无损 WebP）
   │
   ▼
validate.py   校验网格 / 73·15 / Alpha（结构；--pet 在打包后复验）
   │
   ▼
preview.py    生成 GIF + 无损动画 WebP 预览（肉眼检查动画）
   │
   ▼
make_pet.py   出独立帧 + frame-map.json + pet.json + 安装目录 + 两个 ZIP
   │
   ▼
validate.py   --pet 复验已生成的 pet.json 一致性（可选）
```

---

## 二、标准帧目录结构（assemble.py 的输入）

生成的图按状态放进文件夹，帧序号从 0 开始、两位补零；方向帧用角度命名：

```text
frames/
├── idle/00.png … 05.png              # 6 帧
├── running-right/00.png … 07.png     # 8 帧
├── running-left/00.png … 07.png      # 8 帧
├── waving/00.png … 03.png            # 4 帧
├── jumping/00.png … 04.png           # 5 帧
├── failed/00.png … 07.png            # 8 帧
├── waiting/00.png … 05.png           # 6 帧
├── running/00.png … 05.png           # 6 帧
├── review/00.png … 05.png            # 6 帧
└── look-directions/
    0.png, 22.5.png, 45.png, 67.5.png, 90.png, 112.5.png, 135.png, 157.5.png,
    180.png, 202.5.png, 225.png, 247.5.png, 270.png, 292.5.png, 315.png, 337.5.png
```

每张帧**必须已经是 192×208**。生成的图通常不是这个尺寸，先用 `fit.py` 处理。

## 三、各脚本用法

### 1) fit.py —— 缩放定位到标准帧

```bash
# 单张：把 in.png 按可见高度 198px 等比缩放、底部居中，输出 192×208 透明帧
python3 scripts/fit.py in.png -o out.png

# 整目录批量（镜像结构，所有图用同一高度=同一缩放系数）
python3 scripts/fit.py frames-raw/ -o frames/ --height 198

# 特殊：同一来源整行用固定缩放系数（不按高度算）
python3 scripts/fit.py frames-raw/ -o frames/ --scale 0.85 --anchor bottom-center
```

- 默认 `--height 198` = 规范第 5.1 节的基准占画高度；`--anchor` 默认 `bottom-center`（底部居中，保留脚底基线）。
- 最宽/最高姿态装不进单格时，按 `01` 第 5.1 节做尺寸决策（调姿态或整体缩尺度），**别逐帧强行压**。

### 2) assemble.py —— 拼成精灵图

```bash
python3 scripts/assemble.py --frames frames --out spritesheet.png --webp
```

- 输出 `spritesheet.png`（1536×2288）+ `spritesheet.webp`（无损）。
- 15 个透明格由脚本自动留空，**不要自己放空白图占位**。

### 3) validate.py —— 校验

```bash
python3 scripts/validate.py --atlas spritesheet.png --pet pet.json --size-audit
```

- 逐格按 Alpha 检查：73 有效格有内容、15 透明格完全透明；透明格隐藏 RGB 会警告。
- `--pet` 校验 pet.json 版本/行号/帧数/时长一致；`--size-audit` 出 6% 尺度辅助容差。
- 结果写 `structural-audit.json`；结构不通过退出码为 1。

### 4) preview.py —— 动画预览

```bash
python3 scripts/preview.py --atlas spritesheet.png --out previews            # 三项必需
python3 scripts/preview.py --atlas spritesheet.png --out previews --all      # 全部状态+方向
python3 scripts/preview.py --atlas spritesheet.png --out previews --contact-sheet
```

- 每个状态出 GIF + 无损动画 WebP；肉眼检查左右移动方向、跳跃、循环是否正常。

### 5) make_pet.py —— 打包交付

```bash
python3 scripts/make_pet.py --atlas spritesheet.png \
    --id my-pet --name "My Pet" --desc "A cozy coding companion" --kind creature \
    --tags cat,cozy --vibes cozy,calm --out-dir .
```

- 产出（在 `<out-dir>/<id>/` 下）：
  - `spritesheet.png` / `spritesheet.webp`（主图，无损）
  - `pet.json`（自动填好元数据 + 固定 states/animations）
  - `individual-frames/`（73 张单帧）+ `frame-map.json`（73 条映射）
  - `petdex-package/<id>/`（安装目录，**只含 pet.json + spritesheet.webp**）
  - `<id>-petdex.zip`、`<id>-individual-frames.zip` + SHA-256 摘要

## 四、一条命令跑完（示例）

```bash
cd 宠物生成标准包

python3 scripts/fit.py frames-raw/ -o frames/ --height 198
python3 scripts/assemble.py --frames frames --out spritesheet.png --webp
python3 scripts/validate.py --atlas spritesheet.png --size-audit
python3 scripts/preview.py --atlas spritesheet.png --out previews --all
python3 scripts/make_pet.py --atlas spritesheet.png \
    --id my-pet --name "我的宠物" --desc "..." --kind creature \
    --tags tag1 --vibes cozy --out-dir .
# 打包后用生成的 pet.json 做最终一致性复验
python3 scripts/validate.py --atlas spritesheet.png --pet my-pet/pet.json
```

打包完成后的安装目录 `my-pet/petdex-package/my-pet/` 就是能直接导入 AllPet 的东西，见 `04` 文档。
