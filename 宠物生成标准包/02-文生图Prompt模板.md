# 02 · 文生图 Prompt 模板（自己生成宠物图片）

> 本文件是给**你**用的：照着下面的模板，用任意图像生成工具（Midjourney / DALL·E / Stable Diffusion / Flux / 豆包 / 即梦等）自己出图。
> 目标：同一只角色，9 个状态 + 16 个方向，共 73 张透明底 PNG，风格一致、不跑形。
> 固定规格（1536×2288、8×11、每格 192×208、73 有效格）见 `01` 文档，本文件只解决「怎么把图生成出来」。

---

## 一、核心思路：先锁身份，再逐状态生成

生成 73 张图最怕「同一只角色画着画着就变样」。所以顺序固定为：

1. **先只生成 1 张 `idle` 基准图**，反复调到满意 —— 这张是你的「身份基准」。
2. 记下这张图的 **seed / 参考图 / 提示词**，之后每一张都带上它当参考。
3. 每个状态**优先一次生成一整条连贯动作序列**（sequence / 条带），而不是 6~8 张各自独立的图。
4. 方向行：先做 4 个主方向（正上/正右/正下/正左），再补相邻 45° 方向。

---

## 二、角色设定表（先填这个）

把下面几项写清楚，后面所有 prompt 的 `{角色}`、`{画风}`、`{配色}` 都从这里复制，保证一致。

```text
角色名称 / ID：
角色描述（一句话，含物种+关键特征）：
身份特征（必须每张都保留：如 圆框眼镜 / 头顶呆毛 / 蝴蝶结 / 尾巴形状）：
身体结构（几条腿 / 有无翅膀 / 有无伙伴，无则写无）：
画风（扁平像素 / 卡通 / 手绘水彩 / 3D 软萌 …）：
配色（主体色 / 肚皮色 / 配饰色，尽量写死）：
材质与光照（描边粗细 / 阴影方式 / 是否高光）：
身体比例与占画高度目标（默认基准 198 px，见 01 第 5.1 节）：
```

示例（可直接改）：

```text
角色描述：一只圆滚滚的橘猫，奶油色肚皮，戴黑色圆框眼镜，尾巴短而翘
身份特征：圆框眼镜、左耳缺一小角、尾巴末端白色
画风：flat pixel art，粗黑描边，简洁双色阴影
配色：主体 #f5a623 橘、肚皮 #fff3d6、眼镜黑、尾巴尖白
材质：扁平色块，无渐变，1.5px 深色描边
```

## 三、风格一致性锁定技巧（5 条，照着做基本不跑形）

| 技巧 | 做法 |
|---|---|
| ① 固定角色描述 | 每一张 prompt 都用**逐字相同**的 `{角色}` + `{画风}` + `{配色}` 段，只改动作和表情 |
| ② 用 idle 当参考图 | 支持参考图/垫图的工具，每张都垫同一张 idle 基准图，权重调高 |
| ③ 固定 seed | 同工具固定 seed + 同模型，能显著降低随机漂移 |
| ④ 一条序列一张图 | 一个状态出成一条 6~8 格的横向序列（spritesheet / 动画序列），再让脚本切格，避免逐帧独立重画 |
| ⑤ 逐行重试 | 某一状态跑形，只重画那一整行，不要把画坏的格子混进已通过的行 |

> 每次视觉生成都附身份参考图；布局参考（条带的格子间距）只用来排位置，**不要**让工具把参考图里的网格线、背景、标签也复制进成品。

---

## 四、通用提示词骨架

把下面这段拼到每个状态 prompt 前面（或作为 style 前缀）：

```text
{角色}，{画风}，{配色}，{材质}，全身完整入镜，正面视角，
简单背景：纯透明背景（transparent background），无文字，无水印，无网格线，无边框，无速度线，无投影
```

> 输出要求：**透明底 PNG**（不是白底、不是棋盘格贴图）；主体完整、不裁切；不要任何文字/帧号/格线/道具以外的杂物。

## 五、9 个状态逐条 Prompt 模板

替换 `{角色}`、`{画风}`、`{配色}` 为你上面填的内容，其余可照抄。每条给「主动作建议 + 英文 prompt + 关键帧提示」。

### 行 0 · idle（6 帧，160ms）待机
主动作：轻微呼吸起伏 + 偶尔眨眼/尾巴轻摆。
```text
{角色}，{画风}，{配色}，站立待机，轻微上下呼吸起伏，放松的表情，眼睛半闭，
尾巴轻轻摆动，6帧循环动画序列，透明背景，无文字
```
关键帧：每帧只有 2~3 px 的呼吸位移，别让角色大动；6 帧首尾要能无缝循环。

### 行 1 · running-right（8 帧，120ms）向右移动
主动作：面朝右奔跑，四肢交替迈步。
```text
{角色}，{画风}，{配色}，朝画面右侧奔跑，身体前倾，四肢交替迈步，
尾巴向后扬，8帧横向奔跑循环序列，透明背景，无文字
```
关键帧：**明确朝右**（看角色脸的朝向，别凭文件名判断）；8 帧步态首尾衔接。

### 行 2 · running-left（8 帧，120ms）向左移动
主动作：面朝左奔跑。
```text
{角色}，{画风}，{配色}，朝画面左侧奔跑，身体前倾，四肢交替迈步，
尾巴向后扬，8帧横向奔跑循环序列，透明背景，无文字
```
关键帧：如果角色左右对称，可以直接把 running-right 逐帧镜像（保持时间顺序，别倒放）；不对称（如单边眼镜、缺角耳朵）则必须单独生成。

### 行 3 · waving（4 帧，160ms）打招呼
主动作：抬起一只手/爪挥动。
```text
{角色}，{画风}，{配色}，开心地挥手打招呼，一只爪子举起左右摆动，
微笑，4帧循环序列，透明背景，无文字
```
关键帧：4 帧足够表达「抬 → 摆左 → 摆右 → 回」。

### 行 4 · jumping（5 帧，150ms）跳跃/启动
主动作：起跳 → 腾空 → 回落。
```text
{角色}，{画风}，{配色}，向上跳跃，起跳、腾空、落地三个阶段，
四肢舒展，5帧跳跃序列，透明背景，无文字
```
关键帧：**保留真实纵向位移**——起跳离地、腾空最高点、落地回弹，别每帧都贴在同一地面。

### 行 5 · failed（8 帧，150ms）失败
主动作：垂头丧气 / 惊讶困惑。
```text
{角色}，{画风}，{配色}，失败受挫的表情，耷拉脑袋、耳朵下垂，
冒汗或眼睛变成叉叉，8帧循环序列，透明背景，无文字
```
关键帧：清楚表达「受挫/困惑」，和待机、等待的放松表情要能一眼区分。

### 行 6 · waiting（6 帧，170ms）等待中
主动作：抬头张望 / 轻轻摇晃等待。
```text
{角色}，{画风}，{配色}，等待中的姿态，抬头张望或轻轻左右摇晃，
期待的表情，6帧循环序列，透明背景，无文字
```
关键帧：**区别于 idle**——等待要有「在等人/等结果」的期待感，别和待机呼吸混成一组。

### 行 7 · running（6 帧，130ms）工作中
主动作：专注干活（敲键盘/埋头处理）。
```text
{角色}，{画风}，{配色}，专注工作的姿态，快速敲击或埋头忙碌，
认真的表情，6帧循环序列，透明背景，无文字
```
关键帧：这是「正在执行任务」，不是左右移动；动作是原地忙碌。

### 行 8 · review（6 帧，170ms）审查中
主动作：观察 / 检查 / 思考。
```text
{角色}，{画风}，{配色}，审查检查的姿态，一手托腮或凑近观察，
思考判断的表情，6帧循环序列，透明背景，无文字
```
关键帧：和「工作」区分——审查偏「看/判断」，工作偏「动手」。

## 六、16 个方向 Prompt 模板（第 9、10 行）

方向用「视线/朝向」表达，正上为 0°，顺时针 22.5° 一档。**先做 4 个主方向，再做相邻 45°**。

```text
{角色}，{画风}，{配色}，全身正面站立，视线/脸朝向{角度}方向
（0°=正上，90°=正右，180°=正下，270°=正左），
身体朝向保持不变，只有头部/视线转向，透明背景，无文字
```

16 个角度（按固定顺序，第 9 行前 8 个、第 10 行后 8 个）：

```
第9行:  0°  22.5°  45°  67.5°  90°  112.5°  135°  157.5°
第10行: 180° 202.5° 225° 247.5° 270° 292.5° 315° 337.5°
```

关键点：
- 方向靠**头部/视线/传感器/朝向部件**表达，身体尺度和锚点保持稳定。
- 每行 8 帧是同一连贯序列，不要混拼 8 张各自重画的方向单格。
- 4 个主方向必须一眼可辨；对角方向要落在正确象限、不反向。

## 七、输出与命名要求

| 项 | 要求 |
|---|---|
| 格式 | 透明底 PNG（无白底、无棋盘格、无文字/格线/水印） |
| 内容 | 全身完整、无裁切、主体居中、占画高度约 198 px |
| 命名 | 状态帧 `00.png ~ NN.png`（从 0 开始两位补零）；方向帧 `0.png, 22.5.png, …, 337.5.png` |
| 目录 | 每个状态一个文件夹，见 `03` 文档的目录结构 |

## 八、常见翻车与改法

| 现象 | 原因 | 改法 |
|---|---|---|
| 每张图长得不一样 | 没锁身份/seed/参考图 | 固定 `{角色}` 段 + 垫同一张 idle + 固定 seed |
| 背景不是透明 | 工具没出透明 PNG / 贴了棋盘格 | 明确写 `transparent background, PNG with alpha`；换支持透明输出的工具 |
| 移动方向反了/看不出左右 | 靠文件名判断，没看画面 | 按角色脸朝向判断；不对称角色左右必须分开生成 |
| 跳跃像贴地 | 每帧都被贴底 | 保留起跳/腾空/落地的纵向位移 |
| 状态混成一组 | 待机/等待/工作姿势雷同 | 每个状态只做**一个**主动作，姿势、节奏拉开差异 |
| 帧不连贯 | 逐帧独立生成 | 一次生成整条序列，再切格 |
| 有文字/格线/速度线 | prompt 没排除 / 参考图带进来了 | 加 `无文字/无网格/无速度线`，参考图只用身份不复制网格 |
