# 05 · 参考图一键生成（零 LLM）

这是**最省的一条路**：用户只传一张参考图，剩下的生成全程是脚本 + 图生图 API，**不经过任何 LLM、不产生任何 LLM token、不做任何 LLM 决策**。

- **身份** 来自参考图（图片条件生成），不写进文字；
- **动作** 来自 `scripts/gen_prompts.py` 里固定死的模板（9 状态 + 16 方向，恒定不变）；
- **拼图/校验/打包** 复用 `fit/assemble/validate/make_pet` 脚本。

---

## 一、原理（token 和决策都归零）

| 环节 | 谁负责 | 消耗 |
|---|---|---|
| 角色长什么样 | 参考图（图生图 API） | 0 文字 |
| 每个状态怎么动 | 固定模板（`gen_prompts.py`） | 0 决策 |
| 生成几帧、什么角度 | 规格常量（`petformat.py`） | 0 决策 |
| 拼图/校验/打包 | 既有脚本 | 0 LLM |

LLM 完全退出。唯一可调的是「图像生成次数」（图像模型的消耗，不是 LLM token）。

---

## 二、用法

### 1) 先装一个「参考图生图」适配器

打开 `scripts/gen_adapter.py`，在 `CustomAdapter.generate()` 里填你自己的 API 调用（参考图 + prompt → 图）。只需实现这一个方法：

```python
class CustomAdapter:
    def generate(self, ref_path, prompt, out_path, config, meta=None):
        # 1. 调你的 API：reference_image=ref_path, prompt=prompt
        # 2. 拿到结果图字节（url 下载 / base64 解码）
        # 3. 写到 out_path
        ...
```

`config` 来自 `config.example.json`（`api_key_env` / `model` / `size` / `base_url`），API key 建议放环境变量。

### 2) 跑通验证（不联网）

先用 `mock` 适配器端到端跑一遍，确认链路正确：

```bash
python3 scripts/generate.py --ref 参考图.png --adapter mock --id my-pet --name "我的宠物"
```

`mock` 会画占位团子，不调用任何 API。

### 3) 换成你的 API 正式生成

```bash
export MY_IMAGE_API_KEY="..."
python3 scripts/generate.py --ref 参考图.png --adapter custom --config config.json \
    --id my-pet --name "我的宠物" --desc "..." --kind creature --tags cat --vibes cozy
```

---

## 三、两种模式：逐帧 vs 条带（消耗）

| 模式 | 调用次数 | 说明 |
|---|---|---|
| 逐帧（默认） | **73 次**（57 状态帧 + 16 方向） | 每帧一次，精确可控，质量最稳 |
| 条带 `--strip` | **≈11 次**（9 状态条带 + 2 方向条带） | 一次出一条 N 帧横向序列，脚本切格；更省但依赖 API 出条带的能力 |

```bash
# 条带模式：把 73 次压到 ~11 次
python3 scripts/generate.py --ref 参考图.png --adapter custom --config config.json --strip --id my-pet
```

> 说明：条带是「一次生成整条序列再切格」，适合能稳定出等距序列的 API；若你的 API 出条带不稳，用逐帧模式更省心。

## 四、生成后

`generate.py` 会自动接着跑 `fit → assemble → validate → make_pet`，最终产出和手动流程完全一致：

```text
out/<id>/
├── spritesheet.png / .webp
├── pet.json
├── individual-frames/ + frame-map.json
├── petdex-package/<id>/   ← 直接 ./allpet pet import 这个
└── <id>-petdex.zip / <id>-individual-frames.zip
```

导入见 `04-导入AllPet.md`。

---

## 五、为什么能做到「0 LLM」

- prompt 是**常量字符串**（`gen_prompts.py`），不含任何需要模型补全的内容；
- 帧号/角度是**循环序号**（脚本数出来的数字，不是模型决定）；
- 身份一致性靠**参考图**，不靠模型记忆文字描述。

所以整个链路里 LLM 无事可做——它被「参考图 + 固定模板 + 确定性脚本」三者替换掉了。
