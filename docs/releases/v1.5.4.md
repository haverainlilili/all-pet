# AllPet v1.5.4

Codex 任务状态与完成确认、DSH 原页面复用、单平台任务名称轮转；包含 v1.5.0 之后已完成的桌宠修复。

## 本版变化与点击表现

- **单平台也轮转任务名称**：一个平台有多条未完成任务时，前卡每 3.2 秒换名称；多个平台轮换时，各平台再次来到前方显示下一条任务。快照刷新不重置顺序；完成、关闭、隐藏移出循环。前卡 × 关闭当前显示任务；点击堆叠展开平台列表并暂停轮转，收起后继续。降低动态效果冻结轮转，保留多平台半透明后卡。
- **Codex 计划转执行不丢气泡**：新执行轮次恢复同一任务通知；明确的运行、思考、等待在原定 30 分钟窗口内保留，不因两分钟没有日志提前消失。迟到的旧轮次完成事件不会结束新执行。
- **完成确认跨重启保留**：保存 Codex 未读观察基线和暂存已读回执，处理退出期间查看任务、回执先于完成快照到达的情况。新完成轮次不被旧回执清掉。首次安装缺少基线时不猜测旧任务已读，仍需精确窗口识别或点击气泡/×。
- **DSH 优先返回原页面**：macOS 点击无任务的 DSH 平台入口，先聚焦已有浏览器标签，保留 URL 和当前会话；明确不存在才打开首页。拒绝、失败或超时不会重复开页面。具体任务入口仍携带对应会话 ID。
- **DSH 多压缩帧日志**：内置解码器逐帧校验，完整读取追加的独立 Zstandard 帧；损坏或截断不接受旧日志前缀作为最新状态。
- README、产品定义、功能及点击设计、验收边界和安装说明同步更新。已将每次打包/发布必须同步文档写入项目约定。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 14+，Apple Silicon arm64 | `AllPet-1.5.4-arm64.dmg` / `AllPet-1.5.4-arm64-mac.zip` |
| Windows 10/11，x64 | `AllPet-Setup-1.5.4.exe` |
| Linux，x64 | `AllPet-1.5.4.AppImage` / `allpet-desktop_1.5.4_amd64.deb` |

[下载 v1.5.4](https://github.com/haverainlilili/all-pet/releases/tag/v1.5.4)。已有 Node.js 24.18+、npm 11.16+ 与 Git 时，可在三个系统运行同一命令：

```bash
npx --yes github:haverainlilili/all-pet
```

安装器选择最新正式版，校验大小与 SHA-256，再更新原安装位置；重复执行时相同或更高版本跳过。宠物、配置和历史保留。Mac 使用 `/Applications/AllPet.app`，Windows 沿用官方 NSIS，Linux 使用用户目录 AppImage；其它渠道应继续使用原安装渠道。预览用 `--dry-run`，无 Node.js 时直接下载安装包。

Release 附带 `SHA256SUMS`。macOS 使用 ad-hoc 签名、未做 Apple 公证；Windows 未配置代码签名。系统安全提示按系统流程处理；更新后 macOS 原辅助功能身份可能失效，需检查当前应用的实际授权。任务名称轮转、菜单和贴边不需要辅助功能权限。

## 验证与边界

本机已完成 140 项 Node 测试、136 项 Swift 核心自检，以及真实 Electron 源码/打包渲染器和真实 Mac AppKit 定时器验收；单平台 Alpha → Beta → Gamma、刷新稳定、关闭目标、完成移出、展开暂停与多平台下一任务都已覆盖。本轮原生视图由夹具控制偏好输入，Electron 通过 Chromium 媒体偏好模拟验证正常/降低动态效果两种情况；不修改主机系统设置。

正式发布流程再次执行三平台编译、资源、九平台格式、Codex 生命周期、真实任务轮转及成品检查，最终结果见 [发布 Actions](https://github.com/haverainlilili/all-pet/actions/workflows/release.yml) 和 [验收记录](https://github.com/haverainlilili/all-pet/blob/main/docs/平台行为验收.md)。三平台产物与校验清单齐备且检查通过后才公开 Release。

DSH 已有标签页复用仅在 macOS 实现；Windows/Linux 仍由系统打开网址。Codex 桌面已读回执不适用于 CLI/远程账号；缺少基线或有效授权时不能保证自动确认。500 ms 为检查调度周期，不是所有终端两秒内消泡的保证。终端配置和差异见 [接入说明](https://github.com/haverainlilili/all-pet/blob/v1.5.4/desktop/integrations/README.md)。

会话索引/逐字内容导出不随此版本发布。保留 v1.5.0 的统一菜单、贴边收起、九平台和原终端能力。
