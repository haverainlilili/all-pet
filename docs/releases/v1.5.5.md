# AllPet v1.5.5

修复 DSH 升级后运行任务没有气泡、状态停在旧完成记录，以及正式安装包菜单栏/托盘爪印为空白的问题。包含 v1.5.4 既有功能。

## 变化与操作表现

- **DSH v4 识别**：同时支持 `session.v4.jsonl.zstd` 与旧 `session.jsonl.zstd`；同一会话优先读取 v4，不把迁移保留的旧日志当成第二条任务，也不让旧完成事件遮住新活动。任务名、会话 ID、工具和完成状态进入原监控流程；子代理仍过滤。
- **菜单栏爪印恢复**：正式包读取正确的图标资源，缺失或损坏时显示内置爪印。左键或右键点击打开/收起原菜单，连续平台切换、缩放和换宠物保持菜单打开；Esc 与外部失焦按原规则关闭。
- DSH 任务气泡沿用原会话定位，× 沿用原关闭规则；已关闭的完成通知不会因为更新而强行重弹。未增加浏览器定位或辅助功能权限能力。
- README（中英文）、CHANGELOG、产品定义、功能及点击设计、平台验收和安装说明同步更新。会话索引、缓存与逐字导出独立开发内容不包含在本版。

| 系统 | 安装包 |
| --- | --- |
| macOS 14+，Apple Silicon arm64 | `AllPet-1.5.5-arm64.dmg` / `AllPet-1.5.5-arm64-mac.zip` |
| Windows 10/11，x64 | `AllPet-Setup-1.5.5.exe` |
| Linux，x64 | `AllPet-1.5.5.AppImage` / `allpet-desktop_1.5.5_amd64.deb` |

[下载 v1.5.5](https://github.com/haverainlilili/all-pet/releases/tag/v1.5.5)。已有 Node.js 24.18+（含 npm 11.16+）和 Git 时，在终端运行：

```bash
npx --yes github:haverainlilili/all-pet
```

安装器校验大小和 SHA-256 后更新原位置，保留配置、宠物与任务历史；已安装同版本或更高版本时跳过。Mac 唯一入口为 `/Applications/AllPet.app`。Release 附带 `SHA256SUMS`。

## 验收与边界

本地 140 项核心与 145 项桌面测试通过，真实 DSH v4 会话已读到运行状态；Mac 签名后的本地成品验证了 v4 进入 Electron 快照。发布流水线新增三系统 v4 / 旧日志共用集成检查和 Mac 正式包图标/菜单点击检查，最终 Actions、源码提交及资产摘要见 [平台验收](https://github.com/haverainlilili/all-pet/blob/main/docs/平台行为验收.md) 和 [资产记录](https://github.com/haverainlilili/all-pet/blob/main/docs/releases/v1.5.5-assets.json)。

Windows 构建保留 Swift 6.2.4 自带的 SDK 模块定义，避免安装工具自动拉取与固定编译器不配套的上游开发版定义。首轮未公开草稿因该环境问题失败，修正后重新完整验证；不复用失败轮次的部分发布资产。

macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 未配置代码签名。更新后应以实际进程状态核对原有辅助功能授权，不能由签名通过推导权限生效。本版不新增权限要求。DSH 浏览器页面复用仍仅在 macOS 实现；其它系统的会话定位、终端接入及手动查看条件沿用既有说明，不承诺任意终端均两秒内消泡。
