# AllPet v1.5.0

贴边收起、三平台统一菜单与原终端定位。

## 本版变化

- **贴边只露小头**：将宠物拖到可用屏幕任意边缘并松手，隐藏全部任务气泡；新任务、失败提示和悬停不会自动展开。点击小头或拖回屏幕内恢复，重启记住贴边位置。收起本身不确认任务，后台监控与历史继续。
- **三系统统一菜单**：macOS、Windows、Linux Electron 共用 Mac 风格级联菜单。平台开关、全部显示/隐藏、缩放与换宠物可以连续操作；Esc、外部点击及打开其它窗口的动作关闭菜单。
- **原终端定位与查看识别**：运行期间捕获并保存原终端身份；点击完成/失败气泡先确认，再尝试返回已有窗口、标签页或分屏。手动查看仅确认准确匹配的完成轮次，拒绝错误目标、过期进程和迟到回复。
- **终端接入组件**：随包提供 VS Code/Cursor 扩展与 WezTerm Lua 配置；菜单可打开接入说明。macOS 系统桥接在后台运行，不再产生额外菜单图标。
- README、PRD、完整功能设计和点击行为记录同步更新。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| macOS 14+，Apple Silicon arm64 | `AllPet-1.5.0-arm64.dmg` / `AllPet-1.5.0-arm64-mac.zip` |
| Windows 10/11，x64 | `AllPet-Setup-1.5.0.exe` |
| Linux，x64 | `AllPet-1.5.0.AppImage` / `allpet-desktop_1.5.0_amd64.deb` |

[下载 v1.5.0](https://github.com/haverainlilili/all-pet/releases/tag/v1.5.0)。退出旧版后安装；沿用原配置、宠物和任务历史，无需另装 Node.js/Swift。没有应用内自动更新。资产附带 `SHA256SUMS`，macOS/Linux 可运行 `shasum -a 256 -c SHA256SUMS`（只下载部分资产时，其余文件会提示缺失）。

macOS 使用 ad-hoc 签名，未做 Developer ID 签名/Apple 公证；Windows 未配置代码签名。macOS 升级后若原授权失效，需要在系统设置中重新添加当前 AllPet。贴边和气泡展示不需要辅助功能权限；手动查看和窗口定位按系统接口要求授权。

## 终端条件与边界

支持路径包括 Terminal/iTerm2、Ghostty、Windows Terminal/独立控制台、kitty、WezTerm、VS Code/Cursor、Konsole、VTE、X11 单窗口终端和 tmux；接口要求及实际验证范围见 [终端接入说明](https://github.com/haverainlilili/all-pet/blob/v1.5.0/desktop/integrations/README.md)。

VS Code/Cursor 需要安装扩展，WezTerm 需要 Lua 接入，kitty 需要本地控制 socket。已实现适配器不等于每种软件版本均已实测；Warp、SSH/WSL、部分 Wayland 和编辑器面板重新显示仍有限制。500 ms 是检测调度周期，不是所有环境下两秒内消泡的保证。桌面 GUI 会话仍按各平台已有能力识别，不能把 CLI 支持视为所有桌面平台手动查看已接通。

贴边功能适用于 Electron 安装包；源码原生 AppKit GUI 不包含此新增交互。Linux 原生 Wayland 限制全局窗口定位，贴边验收使用 X11。小头取当前宠物待机图上半部分，不同造型的裁切可能不同。

会话索引/逐字内容导出仍为独立开发，不随此版本发布。

## 验证

功能提交已通过 116 项 Node 测试及 [三系统 CI](https://github.com/haverainlilili/all-pet/actions/runs/36311261823) 的 7 项检查，另有 [Windows Terminal](https://github.com/haverainlilili/all-pet/actions/runs/36311261773) 和 [VS Code/Linux](https://github.com/haverainlilili/all-pet/actions/runs/36311261771) 实际终端验收。

四边收起、气泡持续隐藏、鼠标点击/拖动 IPC 恢复、历史保留、缩放和重启恢复已在三系统实际 Electron 窗口与本机测试包验证。负坐标多屏由几何测试覆盖，没有标记为多显示器实机验收。

正式发布流程再次运行核心、资源、九平台格式、Node 回归，以及三系统最终成品贴边测试；三平台打包全部通过并校验资产后公开 Release。最终记录见 [Actions](https://github.com/haverainlilili/all-pet/actions)。
