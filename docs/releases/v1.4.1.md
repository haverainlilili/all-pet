# AllPet v1.4.1

修复 v1.4.0 Windows/Linux 菜单每点一次就关闭的问题。

- 左键或右键托盘图标打开同一个菜单面板。
- 平台勾选、全部显示/隐藏、大小调节、宠物切换、刷新均原位更新并保持打开。
- 提供内嵌大小 −/百分比/＋、宠物缩略图、行内删除与子页返回按钮。
- Esc、关闭按钮、点击外部导致失焦时关闭。安装、删除、打开管理窗、接入修复、配置或退出先关闭再执行。
- macOS 保留 AppKit 原生菜单。原生字体和系统外观仍有差异。

终端 CLI 的日志监控不等于原终端定位；本版没有新增终端聚焦能力，详情见 [终端 CLI 支持说明](../终端CLI支持说明.md)。

## 验证与交付

自动化验证包括 Node 行为测试和真实 Electron 菜单窗口：连续点击、同窗口保留、缩略图加载、非法 IPC 拒绝、Esc 关闭、切换到测试窗口后关闭。CI 在 macOS、Windows 和 Linux xvfb 执行；Windows 发布成品再次验证。使用临时 HOME，不操作真实第三方任务。

GitHub Release 提供 macOS arm64 DMG/ZIP、Windows x64 EXE、Linux x64 AppImage/DEB，以及 SHA256SUMS。旧 v1.4.0 安装包不自动获得修复，需安装新版。发布流程和签名边界沿用 [v1.4.0](v1.4.0.md)：macOS ad-hoc 签名、无 Developer ID/公证；Windows 未配置代码签名。

会话索引/逐字内容导出的独立开发不随本版发布。
