# AllPet v1.4.0

九平台支持、平台气泡显示设置、完成通知修复与完整功能文档。

## 本版变化

- 新增 Cursor、WorkBuddy、Qoder、pi coding agent、智谱 Z Code；Cursor/Qoder 提供可选观察 hooks，Z Code 使用只读 SQLite 并支持 WAL 更新。
- 菜单可以选择显示哪些平台；macOS 勾选后保持菜单打开，设置自动保存。
- 九平台完成/失败气泡点击即确认，定位失败不恢复；保护同会话的新一轮任务。
- 补齐 macOS Electron 的手动查看检测与 Codex 已读回执；过滤有明确来源的内部子代理。
- 修复旧 macOS ZIP 遗漏内置宠物资源的问题；包含 5 个内置宠物、Swift 核心、SQLite/zstd 解码器。

## 下载与升级

| 系统 | 安装包 |
|---|---|
| macOS 14+，Apple Silicon arm64 | `AllPet-1.4.0-arm64.dmg` / `AllPet-1.4.0-arm64-mac.zip` |
| Windows 10/11，x64 | `AllPet-Setup-1.4.0.exe` |
| Linux，x64 | `AllPet-1.4.0.AppImage` / `allpet-desktop_1.4.0_amd64.deb` |

[下载此版本](https://github.com/haverainlilili/all-pet/releases/tag/v1.4.0)。安装包无需另装 Node.js/Swift。退出旧版后安装新版；配置与任务历史继续保存在用户目录。无自动更新，旧包不会自行获得修复。发布资产附带 `SHA256SUMS`，macOS/Linux 可运行 `shasum -a 256 -c SHA256SUMS`（只下载部分资产时其余文件会提示缺失）。

macOS 为 ad-hoc 签名，无 Developer ID/Apple 公证；Windows 无代码签名。首次安装可能触发系统安全提示。升级后若辅助功能失效，由用户在系统设置中重新添加当前 AllPet；不需要为纯状态监控授予该权限。

## 能力边界

九平台的点击确认、显示设置与通知历史规则一致。手动查看检测按平台区分：Codex、Claude、DSH、Grok、pi 在 macOS 满足定位条件时可确认；Cursor、WorkBuddy、Qoder、Z Code 尚未实现，pi 默认日志缺少 TTY 时也不能自动确认。Windows/Linux 尚无同等检测。

500 ms 是调度周期，不是所有客户端 2 秒消泡的保证。受控回执测试与真实导航验收分别记录。新桌面平台主要激活应用，由用户选择会话；不会声称已精确定位。会话索引/逐字导出为独立开发内容，不在本版内。

## 验证

发布源码本地验证：Swift release 构建通过；核心 self-test **136 项**、选择契约 **17 项**、Electron Node **97 项**全部通过。九平台原生格式、Hook 合并/隐私/幂等、SQLite 只读/WAL、五平台查看桥接与 AppKit 三组生命周期均通过。空 HOME、clean PATH 的 sidecar 验证发现 **5 个内置宠物**。

macOS DMG/ZIP 已生成；应用深度严格签名、SwiftPM/SQLite/zstd 资源及 DMG 校验均通过。隔离打包应用在未读→已读回执后 **505 ms** 清除，重启未恢复；这不等于真实客户端导航时延。三平台结果以此版本提交对应的 [CI 与 Release 工作流](https://github.com/haverainlilili/all-pet/actions) 为准。Windows/Linux 的自动化构建与冒烟不替代真实客户端人工验收。
